  OS MODE TOGGLE  (Space + Enter simultaneously)
  Mode persists across power cycles (stored in EEPROM).

  ┌──────────────────┬──────────────────────┬──────────────────────┐
  │ Action           │ Linux / Windows       │ macOS                │
  ├──────────────────┼──────────────────────┼──────────────────────┤
  │ Copy / Paste     │ Ctrl+C / Ctrl+V      │ Cmd+C / Cmd+V       │
  │ Alt-Tab          │ Alt+Tab               │ Alt+Tab (via addon)  │
  │ Snap left        │ Super+Left            │ Alt+Ctrl+Left        │
  │ Snap right       │ Super+Right           │ Alt+Ctrl+Right       │
  │ Screenshot       │ PrintScreen           │ Cmd+Shift+4          │
  │ Terminal toggle  │ Ctrl+`               │ Cmd+`               │
  │ App launcher     │ Super (Activities)    │ Cmd+Space (Spotlight)│
  └──────────────────┴──────────────────────┴──────────────────────┘

  Ctrl/Cmd swap is automatic — physical Ctrl key sends Cmd in Mac mode.

  RGB THEMES  (Layer 1, Q-row)

  │ Nav + W  │ Ocean      — slow cyan breathing             │
  │ Nav + E  │ Aurora     — hue breathing, northern lights  │
  │ Nav + R  │ Starfield  — cool blue twinkle               │
  │ Nav + T  │ Cyberpunk  — magenta, neon cross on keypress │
  │ Nav + Y  │ Forest     — green breathing                 │
  │ Nav + U  │ Party      — spinning rainbow pinwheel       │
  │ Nav + I  │ Splash     — lavender ripple on keypress     │
